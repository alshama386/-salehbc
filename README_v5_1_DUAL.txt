SALEHBC v5.1 EXPERIMENTAL — BTC SOLO / LTC SOLO / BOTH

BOTH splits browser Web Workers between BTC SHA-256d and LTC Scrypt; it does not double hardware compute. With one worker only BTC is assigned until worker count reaches two.

Upload index.html, miner.js, ltc-miner.js, portrait.jpg to GitHub Pages. Existing worker.js from v5 still must be deployed separately in Cloudflare if not already deployed.

WARNING: LTC Scrypt miner is experimental and has NOT passed an independently verified Scrypt test vector or had a pool share accepted. BTC/LTC mining earnings are NOT guaranteed; phone browser mining is not economically viable. Binance exchange deposit addresses may reject direct mining coinbase payouts; verify before relying on them.
